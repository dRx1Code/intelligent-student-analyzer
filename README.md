# intelligent-student-analyzer

# 🎓 Analisador Inteligente de Alunos (Python)

Um projeto prático desenvolvido em Python com o objetivo de exercitar os pilares do **Raciocínio Computacional** (decomposição, reconhecimento de padrões, abstração e algoritmos) através da evolução incremental de um sistema de gestão de notas.

## 🚀 Evolução do Projeto

O sistema foi estruturado em três níveis crescentes de complexidade:

* **Nível 1 (Básico):** Entrada de dados, tipagem, operações aritméticas e estruturas condicionais simples (`if/else`) para cálculo de média individual e verificação de aprovação.
* **Nível 2 (Intermediário):** Implementação de laços de repetição (`while`), fluxo contínuo de execução para múltiplos alunos e validação de integridade dos dados (bloqueio de notas inválidas).
* **Nível 3 (Avançado):** Refatoração para código modular utilizando funções, manipulação de estruturas de dados compostas (listas e dicionários) e geração de métricas estatísticas da turma.

## 🛠️ Tecnologias Utilizadas

* **Python 3.x** (Biblioteca padrão, sem dependências externas)
